# RIVANT Analyst Bot

Telegram-бот: собирает метрики твоих постов в X, раз в неделю присылает анализ, каждый день по расписанию — черновик поста, помогает с ответами клиентам.

Стек: Vercel (сервер) + Turso (база вместо SQLite) + Claude API (мозги) + cron-job.org (расписание, бесплатно).

## Шаг 1. Создай Telegram-бота
1. Открой Telegram, найди **@BotFather**.
2. Команда `/newbot`, придумай имя и username (должен заканчиваться на `bot`).
3. BotFather даст токен вида `123456:ABC-DEF...` — сохрани его.
4. Напиши что-нибудь своему новому боту (любое сообщение) — это нужно, чтобы позже узнать свой `chat_id`.

## Шаг 2. Заведи бесплатную базу на Turso
1. Зарегистрируйся на https://turso.tech
2. Создай базу: `turso db create rivant` (через их CLI) либо через веб-интерфейс.
3. Получи `TURSO_DATABASE_URL` и создай auth token (`turso db tokens create rivant`).

## Шаг 3. Возьми Claude API ключ
1. https://console.anthropic.com → API Keys → Create Key.
2. Сохрани ключ (`ANTHROPIC_API_KEY`).

## Шаг 4. Залей код на GitHub
1. Создай пустой репозиторий на GitHub.
2. В папке проекта:
```
git init
git add .
git commit -m "init"
git remote add origin <ссылка на твой репозиторий>
git push -u origin main
```

## Шаг 5. Деплой на Vercel
1. Зайди на https://vercel.com → New Project → выбери репозиторий.
2. В настройках проекта (Settings → Environment Variables) добавь:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_WEBHOOK_SECRET` — придумай любую случайную строку
   - `TURSO_DATABASE_URL`
   - `TURSO_AUTH_TOKEN`
   - `ANTHROPIC_API_KEY`
   - `CRON_SECRET` — ещё одна случайная строка (для защиты крон-эндпоинтов)
   - `FOUNDER_CHAT_ID` — твой личный chat_id в Telegram (см. шаг 6)
3. Deploy.

## Шаг 6. Узнай свой chat_id
После деплоя открой в браузере:
```
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/getUpdates
```
Найди `"chat":{"id": ...}` — это твой `FOUNDER_CHAT_ID`. Впиши его в переменные окружения на Vercel (шаг 5) и передеплой.

## Шаг 7. Инициализируй базу
Локально, с теми же переменными окружения в `.env`:
```
npm install
node scripts/init-db.js
```

## Шаг 8. Подключи Telegram webhook к твоему Vercel-проекту
Открой в браузере (подставь свой домен и секреты):
```
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://<твой-проект>.vercel.app/api/telegram-webhook&secret_token=<TELEGRAM_WEBHOOK_SECRET>
```
Должно вернуть `{"ok":true,...}`.

## Шаг 9. Настрой расписание на cron-job.org (бесплатно)
Зарегистрируйся на https://cron-job.org и создай задания:

1. **Ежедневные напоминания «пора постить»** — например, в 10:00 и 15:00 и 19:00 по твоему времени:
   URL: `https://<твой-проект>.vercel.app/api/remind`
   Метод: GET
   Заголовок: `x-cron-secret: <твой CRON_SECRET>`

2. **Еженедельный отчёт**, воскресенье 20:00:
   URL: `https://<твой-проект>.vercel.app/api/weekly-report`
   Метод: GET
   Заголовок: `x-cron-secret: <твой CRON_SECRET>`

## Как пользоваться после запуска
- Просто пиши боту в свободной форме: "Сентябрь 10, 15:00, пост про боль revenue up cash down, 4200 просмотров, 87 лайков, 12 ответов, 3 ретвита, 5 переходов, была ссылка" — он занесёт в базу.
- Напиши `идеи` — получишь новые идеи в очередь.
- Напиши `отчёт` — получишь анализ по всем постам прямо сейчас (не дожидаясь воскресенья).
- Напиши `ответ: <текст чужого твита>` — получишь черновик ответа на английском + объяснение на русском.

## Важно про качество анализа
Первые 15-20 постов бот будет собирать, но выводы в отчётах будут помечены как предварительные — на таком объёме данных статистика ненадёжна. Осмысленные паттерны (по времени, темам, форматам) появляются примерно после 40-50 постов.

## Стоимость
- Vercel, Turso, cron-job.org — бесплатные тарифы полностью покрывают этот сценарий.
- Единственная переменная стоимость — вызовы Claude API (парсинг сообщений + генерация). При текущих объёмах (несколько сообщений в день + один отчёт в неделю) это стабильно меньше $1-2/мес.
