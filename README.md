# RIVANT Analyst Bot

Личный Telegram-бот: собирает метрики постов в X, раз в неделю присылает анализ,
каждый день по расписанию — черновик поста, помогает с ответами клиентам.

## Как это устроено

- **Стек:** Vercel (сервер, бессерверные функции) + Turso (SQLite-совместимая
  база) + Claude API (анализ, генерация текста) + cron-job.org (бесплатное
  расписание, дёргает эндпоинты `/api/remind`, `/api/midweek-check`,
  `/api/weekly-report` по `x-cron-secret`).
- **Таймзона:** берётся из `TIMEZONE` (IANA-имя, например `Europe/Kyiv`) —
  переход на летнее/зимнее время учитывается автоматически, ничего не надо
  трогать руками дважды в год.
- **Свежие посты весят больше при анализе:** экспоненциальное затухание веса
  со временем (`RECENCY_HALF_LIFE_DAYS`, по умолчанию 30 дней) — старые посты
  не тянут выводы наравне со вчерашними.
- **Учитывается время до занесения метрик** — 20 просмотров через час и
  20 просмотров через 5 часов после публикации это не одно и то же по
  скорости набора охвата, бот это различает (`hours_since_post`, `views/час`).

## Переменные окружения (Vercel → Settings → Environment Variables)

- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` — от @BotFather / свои
- `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN` — от Turso
- `ANTHROPIC_API_KEY` — с console.anthropic.com
- `CRON_SECRET` — своя случайная строка, проверяется в заголовке `x-cron-secret`
- `FOUNDER_CHAT_ID` — свой Telegram chat_id
- `TIMEZONE` — например `Europe/Kyiv`
- `RECENCY_HALF_LIFE_DAYS` — опционально, по умолчанию 30

⚠️ Ни один из этих секретов не должен попадать в код или в README —
только в переменные окружения Vercel. Если какой-то токен всё же засветился
в git-истории — считай его скомпрометированным и перевыпусти, даже в
приватном/личном проекте: файлы иногда попадают в публичные форки,
логи CI или чужие бэкапы.

## Как пользоваться

- Пиши боту в свободной форме: "Сентябрь 10, 15:00, пост про X, 4200
  просмотров, 87 лайков, 12 ответов, 3 ретвита, 5 переходов, была ссылка" —
  занесёт в базу.
- `идеи` — новые идеи в очередь.
- `отчёт` — анализ по всем постам прямо сейчас.
- `ответ: <текст чужого твита>` — черновик ответа + объяснение на русском.
- Под напоминанием "⏰ Пора постить" — кнопки "✅ Запостила" / "⏭ Пропустить" /
  "🔁 Дай другую идею на этот слот".

## Про качество анализа

Первые 15–20 постов бот собирает, но выводы в отчётах помечаются как
предварительные — на таком объёме статистика ненадёжна. Осмысленные паттерны
(по времени, темам, форматам) появляются примерно после 40–50 постов.

## Стоимость

Vercel, Turso, cron-job.org — бесплатные тарифы полностью покрывают этот
сценарий. Единственная переменная стоимость — вызовы Claude API, при текущих
объёмах стабильно меньше $1–2/мес.
